# Compare two recode_spec versions (or one version vs. package YAML)

Compare two recode_spec versions (or one version vs. package YAML)

## Usage

``` r
diff_recode_spec(version1, version2 = NULL, alias = "pip_inv")
```

## Arguments

- version1:

  `version_id` to compare from.

- version2:

  `version_id` to compare to. `NULL` compares to package YAML.

- alias:

  Stamp alias.
