# Export recode spec from stamp to YAML

Export recode spec from stamp to YAML

## Usage

``` r
export_recode_spec_yaml(path = NULL, version = NULL, alias = "pip_inv")
```

## Arguments

- path:

  Output file path. `NULL` prints to console.

- version:

  Stamp `version_id`. `NULL` uses latest.

- alias:

  Stamp alias.
