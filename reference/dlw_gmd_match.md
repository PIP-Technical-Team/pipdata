# Get the list of current GMD datasets that match the local inventory

Get the list of current GMD datasets that match the local inventory

## Usage

``` r
dlw_gmd_match()
```

## Value

A data.table of matched datasets, or NULL if no match found

## Examples

``` r
if (FALSE) { # \dontrun{
df <- dlw_gmd_match()
head()
} # }
```
