# Check whether the working folder exists and abort if it does not

Check whether the working folder exists and abort if it does not

## Usage

``` r
check_directory(wrk_folder)
```

## Arguments

- wrk_folder:

  A working folder path

## Value

Message if working folder is not available

## Examples

``` r
if (FALSE) { # \dontrun{
check_directory(dlw_data)
} # }
```
